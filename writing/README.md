# Ruby 雅思写作练习室

[打开写作练习室](https://q2257189454-blip.github.io/ruby-ielts/writing/)

130 道大作文按题型、话题和中文立场分类。完整版和简易版使用固定模板，深蓝色是固定句，橙色是本题填充。22 道小作文覆盖折线图、柱状图、饼图、表格、混合图、地图和流程图。每道题配 10 组中英搭配，点开可对照当前版本的范文原句。

[11 月大作文题单](https://q2257189454-blip.github.io/ruby-ielts/writing/#/bank/2/november) 按原题顺序收录 41 道题，其中 30 道是新增范文，11 道沿用已有范文。题库中以金色下划线标出这批标题。

练习包括逻辑链、挖空、限时写作和收藏。个人草稿、填空及收藏由当前浏览器保存在本机。

## 本地运行

在仓库根目录运行 `python3 -m http.server 8000`，然后用浏览器打开 `http://localhost:8000/writing/`。站点由静态 HTML、CSS 和 JavaScript 组成，题库和图片随代码提供。
