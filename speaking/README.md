# 雅思口语练习本

[打开公开练习页](https://q2257189454-blip.github.io/ruby-ielts/speaking/) · [重点题](https://q2257189454-blip.github.io/ruby-ielts/speaking/#/bank/p2/focus) · [通用语料](https://q2257189454-blip.github.io/ruby-ielts/speaking/#/phrases)

公开版用虚构的生活经历做示例，朋友统一使用 Ryan 和 Maggie。P1 和 P3 提供简短双语范答。P2 收录 57 道大陆题卡，按人物 17、事件 19、事物 13、地点 8 编排。个人练习册的 9 组素材配有原题、双语提示、换题重点和中英示范，题号与练习册一致。中文译文可以隐藏，重点话题和小问用黄色标记。保存的个人答案和笔记留在当前浏览器。录音支持回听和下载。

公开页从既有匿名题库中选取 57 张卡。可在 P2 题库页导入配套个人 PDF，范答与串题主干随之切换，个人内容仅保存在该浏览器。P1、P3 与原有笔记的基础题库在 `content/bank.json`，常用表达在 `content/phrases.ts`。在 `speaking` 目录执行 `npm install` 和 `npm run build` 可从源码重建页面。在仓库根目录执行 `python3 -m http.server 8000`，打开 `http://localhost:8000/speaking/` 即可在本地使用。
